# Employee Attrition Analysis

## Project Objective
The objective of this project is to analyze employee attrition patterns and identify the factors that contribute to employee turnover.

## Dataset
IBM HR Employee Attrition Dataset

- Total Records: 1470
- Features: 35
- Target Variable: Attrition

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data Exploration
- Missing Value Check
- Attrition Distribution Analysis
- Age Distribution Analysis
- Gender vs Attrition
- Department vs Attrition
- Overtime vs Attrition
- Monthly Income Analysis
- Job Satisfaction Analysis
- Years at Company Analysis
- Job Role Analysis
- Correlation Heatmap

## Key Findings
1. Employees working overtime have higher attrition.
2. Lower-income employees are more likely to leave.
3. Job satisfaction significantly affects retention.
4. Certain departments experience higher turnover.
5. Employees with fewer years at the company show higher attrition.

## Recommendations
- Reduce excessive overtime.
- Improve employee satisfaction programs.
- Review compensation policies.
- Focus retention efforts on high-turnover departments.
- Strengthen employee engagement initiatives.
